## 🛰 OSINT tool

**→ [gleichleben.de](https://gleichleben.de/)**

OSINT-инструмент для поиска места по фотографии. Загружаешь фото, вытаскивает EXIF, OCR вывесок, скрытые данные в файле. ИИ предлагает кандидатов-локаций с координатами и уверенностью, ставит их на карту. Сверка со стрит-вью (Google и Яндекс.Панорамы, с архивом по годам), поиск зданий по адресу или клику с точным центром, поиск вышек связи и ЛЭП рядом, оценка направления камеры по теням, обратный поиск по картинке (Yandex, Google Lens, Bing, TinEye). Можно задать регион поиска, сильно повышает точность ИИ. В конце отчёт в Markdown с найденной точкой и уликами.
