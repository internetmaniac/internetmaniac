## 🧩 последние решения

| Категория | Задача | Техника |
|---|---|---|
| Reverse | Невероятная утка | UE5 IoStore + Frida, навигация по координатам в игре |
| Crypto | Нулевой отчёт | тождество `a=H(SOURCE), b=a-1` ломает проверку по модулю Мерсенна |
| Misc | Локпик | FPGA-битстрим → Verilog-нетлист → единственный ключ через Z3 |
| Forensics | РакушкаBreach | ручной парсинг битых ShellBag, цепочка XOR-ключей |
| OSINT | Выцветший след | реверс-поиск по фото + сверка трещин и кладки на пиксель |
| Web | Стекадемия | `state` как роутер → open redirect → угон auth code у бота |
